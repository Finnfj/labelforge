SIL Open Font License 1.1 — notices for the fonts bundled with LabelForge
=========================================================================

LabelForge bundles three typefaces. Each is licensed under the SIL Open Font
License, Version 1.1, and each is shipped unmodified: the files served by this
app are exactly the ones published in the corresponding @fontsource package, not
subsetted or converted here. That matters under the OFL, which treats subsetting
and format conversion as creating a Modified Version.

The OFL applies to the fonts. It does not apply to LabelForge itself, which is
MIT — the OFL explicitly permits bundling font software with software under
other licences.

Each font's licence, as it shipped with that font, is reproduced in full below.

  Fira Sans        @fontsource/fira-sans
  Archivo Narrow   @fontsource/archivo-narrow
  JetBrains Mono   @fontsource/jetbrains-mono

A note on the Fira Sans notice: the packaged licence file names only "Google
Inc." The typeface itself is by Erik Spiekermann and Ralph du Carrois, and
upstream carries "Copyright (c) 2012-2015, The Mozilla Foundation and Telefonica
S.A." That attribution is recorded here because the packaged file omits it, not
because it is disputed.
